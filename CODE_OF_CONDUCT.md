# Code of conduct

This project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct.

In short: be respectful and constructive, assume good intent, welcome
newcomers, and focus criticism on ideas and code rather than people.
Harassment, personal attacks and publishing others' private information are
not tolerated.

## Reporting

Report unacceptable behaviour privately to the repository owner through their
GitHub profile, or through the repository's private vulnerability reporting
channel if the matter is sensitive. Reports are handled confidentially. The
maintainers may remove comments, commits or contributions that violate this
code and may ban repeat offenders, following the enforcement guidelines of
the Contributor Covenant.
